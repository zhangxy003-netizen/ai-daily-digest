# The AI Reader · AI 论文日读

> 每天自动追踪 arXiv 热门论文与国内外大厂 AI 动态,用 DeepSeek-V4 生成通俗中文深度解读——让看 AI 像读早报一样轻松。

🔗 **在线访问:** （部署后把你的 Vercel 网址填这里）

---

## 这是什么

一个全自动的 AI 资讯聚合站。它每天:

1. 从 **Hugging Face Daily Papers**(社区投票的每日热门论文)和 **arXiv** 抓取最新 AI 研究,从 **国内外大厂博客 / GitHub** 抓取产品与发布动态;
2. 用 **DeepSeek-V4** 对论文候选按「前沿性 / 影响力 / 科普价值」打分,精选出最值得读的几篇;
3. 为每条内容生成结构化的中文深度解读:**通俗讲解 + 图解 + 关键术语 + 一句话总结**;
4. 自动更新页面,无需人工干预。

整套系统零服务器、零维护成本,配置一次后每天自动运行。

## 特点

- **不是按时间抓最新,而是按热度与价值精选** —— 社区投票热度 + LLM 打分双重筛选,过滤掉低质量论文。
- **三类内容统一呈现** —— 论文 / 行业新闻 / 发布报告,可按类型筛选。
- **深度解读 + 可视化图解** —— 每条配自动生成的对比表 / 流程图 / 数据卡,信息密度高。
- **响应式 + PWA** —— 手机可添加到主屏,像 App 一样使用。
- **真实互动** —— 跨用户的点赞与浏览量统计。
- **学术期刊风设计** —— 衬线排版、克制配色,纯系统字体,国内外访问都快。

## 技术栈

Python · DeepSeek API · GitHub Actions(定时编排)· Supabase(计数)· 原生前端 · Vercel

## 架构

```
数据源(HF Daily / arXiv / 大厂 RSS·GitHub)
        ↓  抓取候选
   DeepSeek-V4 打分精选
        ↓  取 Top N
   DeepSeek-V4 深度解读
        ↓  写回 feed.json
   静态前端(Vercel 托管)
        ↑
  GitHub Actions 每日定时驱动整条流水线
```
